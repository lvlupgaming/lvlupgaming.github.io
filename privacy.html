ClipForge Privacy Policy

Last updated: November 8, 2026

ClipForge is a personal desktop application that runs on its owner's own computer. It is used only by its owner to create short video clips and upload them to the owner's own YouTube channel(s). This policy explains how ClipForge handles data, including data accessed through YouTube API Services.

Information ClipForge accesses

When the owner connects a YouTube channel, ClipForge uses Google OAuth and the YouTube Data API to access:

  • Basic channel information (channel ID, channel name, custom URL and channel thumbnail), to show which channel is connected.
  • Permission to upload videos, so ClipForge can publish clips the owner has approved.

ClipForge does not read, collect or analyze the owner's other YouTube data, viewers' data, comments, subscribers or analytics.

How information is used

The accessed information is used only to display the connected channel inside ClipForge and to upload videos the owner has chosen to publish. It is not used for advertising, profiling or any other purpose.

Storage and security

OAuth tokens and channel information are stored only on the owner's own computer, encrypted with AES-256 using a key protected by the Windows operating system. ClipForge has no servers and does not send this information to the ClipForge developer or any third party. Video files are uploaded directly from the owner's computer to YouTube.

Sharing

ClipForge does not sell, rent, share or transfer any user data to anyone. Data is only sent to Google/YouTube as needed to perform uploads the owner requests.

Retention and deletion

Data stays on the owner's computer until the owner disconnects the channel in ClipForge (which deletes its stored tokens) or deletes the ClipForge data folder. Access can also be revoked at any time from the Google security settings page: https://myaccount.google.com/permissions.

YouTube API Services

ClipForge uses YouTube API Services. By using ClipForge you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Children

ClipForge is not directed at children and does not knowingly collect data from children.

Changes

If this policy changes, the updated version will be posted on this page with a new "Last updated" date.
